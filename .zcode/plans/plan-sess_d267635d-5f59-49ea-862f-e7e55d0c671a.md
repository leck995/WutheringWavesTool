## SlashView AreaCell 重构计划

### 修改文件
仅修改 `SlashView.java` 的 `AreaCell` 内部类。

### 具体改动

**1. 构造函数** - 移除 `setSpacing(8)`（CSS 已通过 `.matrix-team-card` 设置）

**2. `createHeader()` - 照搬 NewTowerView 结构**

NewTowerView 结构：
```
[01] [VBox(TEAM / 第N队)] [spacer] [积分 + score]
```

SlashView 改为：
```
[icon] [VBox(FLOOR / challengeName)] [spacer] [rank] [积分] [score]
```

- 将 icon（ImageView）从 `title.setGraphic(icon)` 改为 header 的第一个子元素（替代 NewTowerView 的 team-index 数字位置）
- titleBox 保持 VBox 上下结构：eyebrow("FLOOR") + title(challengeName)，移除 icon 的 graphic 绑定
- rank 移到积分左侧

**3. `createHalfRow()` - 照搬 NewTowerView 的 team-stage 样式**

旧左侧 VBox：
```
[01] team-index (31px 彩色) + FLOOR team-eyebrow (11px) + score team-score (17px)
```

新左侧 VBox（使用 team-stage 样式类）：
```
FLOOR round-info (12px muted) + 01 pass-info (20px bold)
```

完全对齐 NewTowerView 的 "第N轮" + "X/Y" 风格。

**4. 角色行和 Buff 帧保持不变** - 已使用相同 CSS 类

### 无需修改
- CSS (Tower.css) - 所有样式类已定义
- FXML (SlashView.fxml) - 布局不变
