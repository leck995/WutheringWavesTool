快速开始

leck大约 6 分钟

遵循这篇快速开始文档，你可以快速上手鸣潮助手。

系统要求

要求规格
最低系统版本Windows 10 Build 1809 (22H2)
Windows 11
推荐版本Windows 11

Windows 10 Build 1809 以下的版本默认无法启动，但可以通过修改助手配置完成启动，具体请参考 常见问题解答。

下载鸣潮助手

鸣潮助手主打轻快简洁、解压即用，故以免安装压缩包发布，不提供可执行的 EXE 安装版。

前往 Github 发布页，下载最新版本的 WutheringWavesTool-xxx.zip，解压后启动 WutheringWavesTool.exe。

提示

自助手 1.2.4 后，助手已提供自动更新功能。但受限于网络原因，部分用户可能无法成功自动更新。

如果自动更新失败，请手动下载最新压缩包覆盖旧版本即可。覆盖安装不影响原有数据，不会丢失数据。

完成游戏基本设置

提示

目前助手的游戏下载功能尚未完成开发，无法使用，只能选择本地已安装的鸣潮。

提示

请注意：1.2.3 之前不支持鸣潮启动器与游戏本体分离，必须保证 Wuthering Waves Game 在 Wuthering Waves 目录下。如游戏本体与启动器分离，可将本体迁移至启动器文件夹下，或新建文件夹嵌套。

首次启动，请先前往 游戏管理 界面，完成游戏根目录相关设置。

  1. 点击 设置安装游戏目录 按钮，选取游戏本体所在目录
  2. 默认情况下区服会自动识别；如果识别错误，请手动修正
  3. 请务必选择正确的区服，错误的区服可能会导致助手异常

游戏安装目录为 鸣潮本体所在目录，而非鸣潮启动器所在目录。安装目录内必定有一个 Wuthering Waves.exe 文件。

以安装在 C:\Game\Wuthering Waves\Wuthering Waves Game 的游戏为例，只需选中 Wuthering Waves Game 文件夹即可。

完成设置后，你可以通过助手启动鸣潮、获取抽卡记录、使用游玩统计功能。

如果在使用中有问题，请参考 常见问题解答。

添加第一个库街区账号（可选）

提示

因国际服不支持库街区，国际服以及不需要库街区功能的用户可跳过该教程，并在 设置 → 基础设置 → 开启禁用库街区，然后重启助手。

目前角色查看、深塔历史、签到等功能需要接入库街区。只有完成账号添加，方能正常使用上述功能。

  1. 通过左侧导航栏进入 账号界面
  2. 依次填写 用户 ID、游戏 ID、Token 三项
  3. 请务必选择一个账号勾选主账号，否则部分功能无法正常使用
  • 用户 ID：库街区的用户 UID
  • 游戏 ID：鸣潮的特征码
  • Token：库街区的用户 Token

如不知如何获取 Token，请查看 Token 获取教程。

常见问题解答

1. 提示无法获取抽卡数据连接

务必确保游戏安装目录正确。

  • 获取前必须打开游戏内的抽卡历史界面
  • 如果曾经修改过游戏配置（例如修改画质），请关闭鸣潮进程后：
    • 找到 Wuthering Waves Game\Client\Saved\Config\WindowsNoEditor\Engine.ini
    • 寻找并移除 global=none（不会影响其余修改）
    • 或者寻找并移除（视情况而定，可能部分存在）：
[Core.Log]
Global=off
LogInteractiveProcess=all off

2. 已经添加账号且设置为主账号，却仍提示账号不存在

可尝试重启助手。

3. 我是国际服，无法使用库街区，一直弹窗提醒怎么办？还有国际服能使用哪些功能？

国际服玩家可在 设置 → 基础设置 中开启禁用库街区，这样就不会再出现相关弹窗。禁用库街区后，所有剩余功能都是国际服可以使用的。

4. 安装新版本可以覆盖安装吗？不覆盖如何迁移助手旧数据？

如无特殊说明，均支持覆盖安装。若同时存在旧版本与新版本，将旧版本数据迁移到新版本，只需将助手安装目录中的 data 文件夹、setting.json 和 sqlite.db 迁移到新版本目录中即可。

5. 助手的数据保存在哪里？如何转移助手数据以保证数据不丢失？

助手所有数据均保存在助手安装目录。迁移时只需将安装目录中的 data 文件夹、setting.json 和 sqlite.db 复制到新版本助手安装目录中。

6. 如何在桌面启动助手？

右键鸣潮助手启动程序 → 创建快捷方式 → 将快捷方式拖动到桌面即可。

7. 无法打开助手，直接闪退无响应？

助手只支持 Windows 10 及以上系统，请检查系统版本是否满足需求。如果 Windows 10 版本号低于 1809，用记事本打开助手安装目录的 app/WutheringWavesTool.cfg 文件，删除以下文本：

[JavaOptions]
java-options=-Djpackage.app-version=1.0
java-options=-XX:+UseZGC

注意

如果是第三方修改系统或精简系统，请勿反馈与提交 issue，这些不在助手的支持列表中。

8. 频繁提示网络异常，无法检测新版本怎么办？

受限于部分用户网络环境，可能无法成功获取更新数据。可前往设置关闭检测更新。请注意：一旦关闭，后续助手更新将不会提示，需要自行前往 Github 下载。

9. 我是 WeGame 玩家，如何使用助手？

WeGame 暂时不支持直接通过助手启动，需要额外操作。受限于部分情况暂无法直接通过助手设置，具体请加 QQ 群 984939498 获取教程。

10. 助手使用库街区后，提示「账号失效需要重新登录」

由于库街区的 Token 失效，重新在账号界面添加库街区账号即可。

11. 提示无法访问远程资源仓库，检查网络并正确设置仓库源怎么办？

可尝试在设置中切换资源仓库。

12. 提醒多开限制，启动缓慢且游戏窗口不会出现

部分用户在开启高级启动时会出现该问题。可暂时关闭高级启动（帧率修改后不影响），后续版本将会修复。

13. 添加多个库街区账号时，账号会要求重新登录

浏览器使用无痕 / 隐私模式，或切换浏览器。

14. 库街区签到失败，且其他功能正常

退出当前账号，重新登录库街区。

15. 使用助手启动游戏会导致卡顿

助手会以官方默认 DX 方式（依电脑配置与启动程序而定）启动游戏。可以在游戏管理中指定 DX 版本，如 DX11、DX12。

16. 助手窗口很大，且无法调整窗口大小

  1. 请先查看是否开启了最大化窗口
  2. 尝试拖动窗口右下角调整窗口大小
  3. 如果仍无法解决，用文本编辑器打开助手安装目录的 setting.json，修改为下方大小：
"appWidth" : 1300.0,
"appHeight" : 800.0,

17. 助手的默认窗口过大或过小，且窗口调整不满足需求

可前往设置调整窗口缩放率。
